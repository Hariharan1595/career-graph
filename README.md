# CareerGraph

A graph-based job recommendation platform built with Spring Boot, React, and CognoDB.

## Features

- Job recommendations
- Match percentage
- Skill gap analysis
- Graph Explorer
- Job search
- Responsive UI

## Technology Stack

### Backend
- Java
- Spring Boot
- Maven
- Neo4j Java Driver

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Database
- CognoDB
- openCypher
